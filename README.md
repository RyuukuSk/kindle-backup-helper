## ✨ 为什么做这个软件

**核心目的：备份越狱环境。**

很多 Kindle 用户折腾越狱，装上了 KOReader、各种插件、自定义字体和配置。这些成果**不在亚马逊云端**，官方也不会帮你保存。一旦设备损坏、误操作、恢复出厂或换新机，几个月的心血就没了。

于是有了这个工具——把「备份越狱环境」这件麻烦事，变成**点一下就完成**：

- 🔧 **越狱环境完整备份**：KOReader、插件（koreader / extensions / mrpackages）、字体、配置全部原样打包
- 📚 **电子书备份**：自己导入的 azw3 / mobi / epub / pdf 一键备份，不受容量限制
- ♻️ **一键还原**：换机或恢复后，把环境原样写回，越狱成果不丢失

> 🤖 **说明**：本项目由 **AI 辅助开发**（代码生成、界面设计与文档编写均在 AI 协助下完成），需求来自作者对 Kindle 越狱数据安全的真实需求。

## 🎯 三种备份模式

| 模式 | 内容 | 适用场景 |
|------|------|----------|
| **环境备份** | 备份 KOReader / 越狱插件 / 字体等到镜像（macOS）或目录（Windows） | **保护越狱环境 —— 本软件核心用途** |
| **全量备份** | 环境 + 图书一起备份 | 最完整的兜底方案 |
| **仅图书** | 只备份电子书到本地文件夹 | 只想保存书籍，不限容量 |

### 关于「越狱会不会失效」

- 越狱状态本身由 Kindle **设备内部系统分区**的证书/标记决定，USB 备份读写的是用户可见区 `/mnt/us`，**不会触碰、也不会破坏越狱核心**。
- 环境/全量备份会**完整包含** `koreader`、`extensions`、`mrpackages` 等越狱插件目录，还原后原样恢复。
- 备份和还原的效果在 macOS 与 Windows 上完全一致（macOS 用镜像 `.img`，Windows 用目录方式）。

### 已测试机型

| 机型 | 状态 |
|------|------|
| **Kindle Voyage** | ✅ 已实测可用（越狱 + KOReader 环境） |

### 核心功能

- ✅ **自动检测 Kindle 连接** —— USB 插上即识别，状态一目了然
- ✅ **智能图书扫描** —— 自动找出 Kindle 上所有含书的文件夹，不遗漏、不误判
- ✅ **备份位置自由选择** —— 不预填默认路径，由你决定备份到哪
- ✅ **实时进度显示** —— 进度条 + 百分比 + 详细日志，过程透明
- ✅ **一键还原** —— 从备份镜像 / 目录 / 图书文件夹还原回 Kindle
- ✅ **跨平台** —— macOS（Intel + Apple Silicon）与 Windows（7/10/11）同一套代码

## 📦 下载与安装

### 支持的平台

| 系统 | 架构 | 安装包 |
|------|------|--------|
| macOS | Intel (x64) | `Kindle 备份助手-1.1.0.dmg` / `-mac.zip` |
| macOS | Apple Silicon (M1/M2/M3) | `Kindle 备份助手-1.1.0-arm64.dmg` / `-arm64-mac.zip` |
| Windows | 7 / 10 / 11 | `Kindle 备份助手 Setup 1.1.0.exe`（安装版）或便携版 |

### macOS 安装

1. 前往 [Releases](../../releases) 下载对应架构的 `.dmg`
2. 打开 dmg，把「Kindle 备份助手」拖入「应用程序」文件夹
3. 首次打开如提示「无法验证开发者」，请右键点击应用 → 选择「打开」→ 再次点击「打开」

### Windows 安装

- **安装版**：双击 `Setup 1.1.0.exe`，按向导安装
- **便携版**：直接双击 `1.1.0.exe` 运行，无需安装

## 🚀 使用方法

1. 用 USB 数据线连接 Kindle，在 Kindle 上选择「**传输文件**」模式
2. 打开「Kindle 备份助手」，等待状态卡显示绿色「**Kindle 已连接**」
3. 选择备份模式（**环境备份** / 全量备份 / 仅图书）
4. 点击「选择文件夹…」指定备份位置
5. 点击「**开始备份**」，等待进度条走完即可

> 💡 **还原**：插上 Kindle，选择备份所在位置，点击「还原到 Kindle」，选择要还原的内容，确认后即可写回设备。

| 项目 | 说明 |
|------|------|
| 框架 | Electron 22（最后一个同时支持 Windows 7 和 macOS 10.13+ 的版本） |

## ⚠️ 注意事项

- **备份前请确认 Kindle 存储充足**，全量备份会占用较多空间
- 还原操作会**覆盖** Kindle 上的同名文件，请谨慎确认
- 备份数据保存在本地，请自行做好重要数据的异地冗余
- 支持越狱 / KOReader 环境，但请遵守设备使用规范
