# Kindle 备份助手（跨平台版）

> 为 **越狱 Kindle 用户**做的备份工具：一键完整备份 KOReader、越狱插件、字体与配置，
> 换机 / 重置 / 插件翻车后原样还原。电子书备份顺带支持。
> macOS（Intel + Apple Silicon）与 Windows 7/10/11 通用，纯本地运行，不联网。

## 支持的操作系统

| 系统 | 版本 | 安装包 |
|------|------|--------|
| macOS（Intel） | 12.7.6（Monterey）及以后 | `Kindle 备份助手-1.1.1.dmg` / `-1.1.1-mac.zip` |
| macOS（Apple Silicon） | 12.7.6 及以后 | `Kindle 备份助手-1.1.1-arm64.dmg` / `-1.1.1-arm64-mac.zip` |
| Windows | 7 / 10 / 11 | `Kindle 备份助手 Setup 1.1.1.exe`（安装版）或 `Kindle 备份助手 1.1.1.exe`（便携版） |

未签名的 macOS 版首次打开需右键 →「打开」；Windows 版若被 SmartScreen 拦截，点「更多信息」→「仍要运行」。

## 三种模式

| 模式 | 备份内容 | 产物 |
|------|----------|------|
| 仅图书 | 电子书 | 备份目录下的 `图书/` 文件夹 |
| 越狱环境（推荐） | KOReader、插件、字体、配置等 `/mnt/us` 全部内容（不含图书） | macOS：`.sparseimage` 稀疏镜像；Windows：`*_备份目录` 文件夹 |
| 全量 | 越狱环境 + 图书 | 环境镜像 + `图书/` 文件夹（图书只存一份，不重复占用空间） |

还原时选择同一模式即可；「全量」会先恢复环境镜像，再恢复图书文件夹。

## 关于「越狱」会不会失效

- 越狱状态由 Kindle 设备**内部系统分区**的证书与标记决定；USB 备份读写的只是 `/mnt/us`（USB 可见区），不会触碰、也不会破坏越狱核心文件。
- 环境备份 / 全量备份会**完整包含** `koreader`、`extensions`、`mrpackages`、`fonts`、`kmc`、`libkh` 等越狱插件与配置目录，还原后原样恢复（实测：KOReader 目录 3862 个文件零缺失）。
- Windows 的「目录备份」与 macOS 的「镜像备份」内容完全一致，只是形式不同（文件夹 vs 单个镜像文件），还原效果等同，不会导致越狱失效。
- macOS 在 exFAT 上产生的 `._xxx` 元数据垃圾文件会被自动跳过，不影响还原结果。

## 备份体积说明

macOS 使用**稀疏镜像**（`hdiutil -type SPARSE`），镜像文件只随真实数据增长，占用 ≈ Kindle 实际数据量。
（v1.1.0 及更早版本使用默认的 UDRW 格式，会在创建时一次性预分配整个容量，导致 2.5G 的内容产生 4GB 的备份文件。）

## v1.1.1 修复记录

- 修复备份体积虚胖：改用稀疏镜像，2.5G 的内容不再产生 4GB 的备份。
- 修复「备份刚结束就还原」挂载失败（镜像卸载未等待完成 → 资源暂时不可用）；现在会等待卸载完成并自动重试挂载。
- 修复备份失败仍报成功、以及异常时界面按钮永久禁用（只能重启软件）的问题。
- 「全量」模式不再把图书在镜像和文件夹里各存一份，减少一半冗余。
- 「选择映像」按钮真正生效：可手动指定用哪个备份文件还原；映像类型支持 `.sparseimage`。
- 备份/还原过程中若有文件复制失败（如空间不足），会在日志中汇总提示，而不是静默跳过。

## 隐私说明

- 纯本地工具，不联网、不上传任何数据。
- 备份位置由用户自行选择，软件不预填、不写入任何默认目录。
- 代码中不含任何开发者个人信息或机器路径。

## 技术说明

- 框架：Electron 22.3.27（最后一个同时支持 Windows 7 和 macOS 10.13+ 的版本）
- 跨平台复制：Node.js 原生 `fs` 递归复制（保留空目录，精确跳过 macOS 垃圾文件）
- macOS 镜像：`hdiutil` 稀疏镜像 + `rsync`
- Windows：无 hdiutil 等价工具，环境备份采用目录复制（内容等价）

## 开发

```bash
npm install
npm start          # 本地运行
npm run dist:mac   # 打包 macOS
npm run dist:win   # 打包 Windows
```
